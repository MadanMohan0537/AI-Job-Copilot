# Getting Help

AI Job Copilot is Madan's open-source project and is maintained in limited time. Here's how to get help efficiently.

## Where to ask

| Question type | Where |
|---|---|
| **Bug** (something is broken) | [AI Job Copilot Issues](https://github.com/MadanMohan0537/AI-Job-Copilot/issues) — use the Bug Report template |
| **Feature idea** | [AI Job Copilot Issues](https://github.com/MadanMohan0537/AI-Job-Copilot/issues) — use the Feature Request template |
| **How do I...?** | [AI Job Copilot Discussions](https://github.com/MadanMohan0537/AI-Job-Copilot/discussions) |
| **Setup help** | Check [docs/FAQ.md](docs/FAQ.md), then [docs/SETUP.md](docs/SETUP.md), then open a discussion |
| **Security vulnerability** | Use the private reporting instructions in [SECURITY.md](SECURITY.md) |

## Before opening an issue

1. Search existing issues — someone may have reported it already
2. Run `npm run doctor` — it catches most setup problems
3. Include your OS, Node.js version, and the CLI you're using (Claude Code, OpenCode, etc.)

## What NOT to use GitHub Issues for

- General questions about job searching
- Requests for personal career advice
- Support for unrelated forks or unofficial distributions
- Asking the maintainer to review your CV

These will be closed and redirected to the appropriate channel.
